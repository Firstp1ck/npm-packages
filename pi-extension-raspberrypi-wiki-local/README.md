# Raspberry Pi Wiki Local for Pi

Lets Pi search a local Raspberry Pi documentation collection.

## What you can do

- Searches a local Raspberry Pi documentation collection.
- Reads focused sections with local citations.
- Updates the local documentation through one setup command.
- Includes status and smoke-test commands.

## Install

Install it through Pi:

```bash
pi install npm:@firstpick/pi-extension-raspberrypi-wiki-local
```

Restart Pi if the package does not appear in your current session.

## How to use it

Run `/raspberrypi-wiki-local-setup` once. Then ask Pi a Raspberry Pi question normally and use the status command if you need to confirm the local documentation is ready.

## Before you start

Run `/raspberrypi-wiki-local-setup` once, then use `/raspberrypi_wiki-status` to confirm the local documentation is ready.
