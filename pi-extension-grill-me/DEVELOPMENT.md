## Development symlink

For local development, symlink Pi's global extension entry to this package:

```bash
ln -s /home/firstpick/pi-coding-agent-forge/pi-extension-grill-me/index.ts ~/.pi/agent/extensions/grill-me.ts
```

Then run `/reload` in Pi.
