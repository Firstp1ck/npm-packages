Design decisions and architecture

One scoped density layer

A localized block near the end of public/styles.css overrides existing component classes without changing markup, JavaScript, APIs, persistence, or execution behavior.

Responsive rules remain authoritative

The compact block precedes responsive rules. A dedicated post-compact @media (pointer: coarse) block restores 44px targets for every compacted interactive surface.

Files tree is the Git visual source

Git folders/files share the Files row palette, border geometry, and interaction values while intentionally using tighter dimensions. Git status letters, conflict/stage colors, and line statistics remain unchanged.

Rollback stays trivial

The change is presentation-only and additive. Reverting the CSS block and focused test restores the former layout; no data or settings migration exists.

Accepted · fixed Coarse-pointer shrink

Reviewers identified that desktop compact values also won on touch devices for controls without later overrides. A dedicated coarse-pointer block now restores 44px targets across App Runner, Subagents, Git, and Guided Git.

The final OpenRouter review found button.git-workflow-step missing from the touch-floor selector. It was added to CSS and test coverage; follow-up run 0c963c3f verified resolution with 95/100 confidence.

Accepted · fixed Regression-contract strength

The test compares actual visual declarations from the Git and Files blocks, asserts exact Git density values, and checks source-order relationships.

Accepted · fixed Directory container padding

The second screenshot revealed that tightening summaries alone could not remove the gap. The global details card rule still added 0.6rem padding above and below each folder. A scoped `.git-side-panel-folder` reset now removes that padding, radius, border, and background in both open and closed states while leaving file rows untouched.

The selector loop enumerates repository toggle, tab, folder summary, and file row; the coarse-pointer rule restores every one to 44px.

Rejected as blocker Git focus outline
