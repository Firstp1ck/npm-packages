Fast Mode Aggregated Thinking

Fast mode combines thinking segments separated by tool calls into one native disclosure per user turn. Live thinking starts expanded, stored thinking starts collapsed, and explicit user toggles survive content reconciliation.

Result: current reasoning remains visible while streaming, historical thinking stays compact by default, and normal-mode transcript rendering is unchanged.

Confidence: 92/100. The role-specific disclosure state machine, focused executable checks, keyed reconciliation, cache updates, and a fresh provider-diverse correction review quorum were verified. No live browser click-through was performed.

Usage, rollout, and limitations

  1. Enable Fast under Output processing.
  2. While a turn is running, the thinking (live) disclosure is expanded by default.
  3. After reconciliation, stored thinking appears as one collapsed row labeled thinking or thinking (N segments).
  4. Select either row or focus it and press Enter/Space to override its current open/closed state.
  • The existing global thinking-visibility setting still hides the disclosure entirely.
  • Expansion state is terminal-tab-local and intentionally does not persist across page reloads.
  • No live browser screenshot or automated DOM click test was performed.
  • Rollback is a direct revert of the localized fast-mode renderer, CSS, copy/cache tests, plan, and report; no migration is involved.
