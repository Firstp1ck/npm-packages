Residual risks, usage, and rollback

No live browser execution

Pointer, focus, and mobile stacking behavior is inferred from source contracts and two reviews rather than observed in a browser.

Deleted paths

A deleted worktree file cannot be opened through the live-file viewer and produces the existing visible error. Historical/base preview needs separate product scope.

Usage

Expand a Git repository and activate an existing file row. The viewer opens on the current eligible tab or switches to another tab whose cwd contains the file.

Git actions

Right-click, Context Menu, or Shift+F10 still opens the Git action menu; primary click/Enter/Space now opens the file.

Rollback

Remove row activation, restore the context-menu cursor and old inline Changes-dialog translation, then remove the focused test file.
