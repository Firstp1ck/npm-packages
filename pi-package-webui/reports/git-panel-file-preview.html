Category behavior

Staged

Runs a file-scoped git diff --cached and renders index-vs-HEAD additions/deletions in the split grid.

Changes

Runs a file-scoped unstaged diff and renders worktree-vs-index changes, even for a mixed staged/unstaged file.

Conflicted

Uses git diff --cc. Combined @@@ hunks intentionally render as bounded raw text because the existing grid has only old/new columns.

Untracked

Verifies the path through Git, then shows all text lines as additions. Binary, unreadable, missing, or over-500-KB content receives an explicit notice.

Deleted

If live source is gone but Git still returns a diff, the viewer opens read-only in Changes mode and disables Source, Preview, Save, and default-editor actions.

Source and Preview

Existing files remain editable in Source. Markdown Preview remains available. Entering Changes clears any stale source selection bar.

Architecture and request flow

Backend

readGitFileDiff allowlists four categories, confines one repo-relative path, disables external diff/textconv, applies a five-second/500-KB bound, and returns raw snapshot metadata.

Frontend

activeFileViewer.gitChanges carries the open-time snapshot. Existing parsers/renderers produce split rows; dedicated fallbacks cover loading, errors, empty output, truncation, conflicts, and untracked data.

Race model

One serial identifies the viewer open and another identifies its changes request. Closing the viewer invalidates pending opens; tab-generation checks reject cross-tab responses.

Usage, residual risks, and rollback

Usage

Open Git, expand a repository, and activate a file row. The viewer starts on Changes. Use Source for the live editable file or Preview for Markdown.

Refresh

The diff is an open-time snapshot. After saving Source or after external Git changes, reopen the Git row to reload the relevant category.

Conflict and large-file limits

Combined conflict hunks show raw bounded text. Single-file diffs cap at 500 KB; oversized untracked files show an explicit notice.

Residual validation gap

No live browser run verified pointer focus, narrow-pane scrolling, or mobile stacking. Static/vm and real HTTP/Git evidence cover the code paths.

Unrelated work preserved

The existing numpad-decimal hunks and untracked test remain outside this feature and continue to pass their focused test.

Rollback

Remove Changes DOM/CSS/state, restore category-free Git opens, then remove /api/git-file-diff and its harness cases. The original click-to-open behavior remains independently revertible.
