Workflow Subprocess Minimize / Restore

A lightweight Pi WebUI feature that lets users collapse the verbose Workflow Subprocesses output while keeping the workflow identity, run summary, safety actions, and a clear Restore control available.

Conclusion: the subprocess card now has an accessible per-tab Minimize/Restore control. Minimized cards stop building the terminal body, release the workflow sizing rule when every workflow card is minimized, and restore the existing output expansion plus scroll/follow state. A validated follow-up replaced the earlier fixed slot with intrinsic growth up to a viewport-safe cap.

Scope: public/app.js, public/styles.css, and tests/mobile-static.test.mjs. Syntax, the focused test, all 41 package test files, scoped diff checks, two independent minimize/restore reviews, and a headless Chrome geometry probe passed. Confidence: 94/100; focus and cross-tab interaction remain recommended manual checks.

Interaction and architecture

Expanded

Everything stays available

The title, run/phase/task metadata, Status, Abort, Clear, output disclosure, terminal, and follow-state message retain their current behavior.

Minimized

Header remains actionable

The terminal body is not built, but workflow context and actions remain visible. The toggle changes to Restore and exposes its collapsed state.

Restored

Output state returns

The terminal is rebuilt from the latest payload. Existing browser-memory maps recover inner expansion and per-run scroll/follow state.

Responsive

Touch target preserved

The control reuses the inspector button palette and receives the existing 44px mobile/coarse-pointer minimum height.

Intrinsic height

Content sets the size

The outer area uses flex: 0 0 auto up to min(44rem, 68dvh); the terminal uses a max-height, not a forced height. Mobile remains capped at 34dvh.

Usage, rollout, rollback, and limitations

Use

Minimize and restore

Select Minimize in the Workflow Subprocesses header. The terminal disappears and the control becomes Restore. Select Restore to rebuild the latest output.

Rollout

Reload only

This is a browser-only renderer change. No migration, configuration, dependency, server restart contract, or workflow payload version is required.

Rollback

Localized revert

Revert the per-tab Set/setter, minimized renderer branch, intrinsic sizing/cap rules, and static assertions. No data rollback is necessary.

Manual check

Focus and tab continuity

Geometry is browser-probed. Still recommended: minimize during a live run, switch tabs, let updates arrive, restore, and confirm keyboard focus plus per-tab scroll continuity.
