Architecture and data flow

Async

Canonical effective values

Each child resolves its own lifecycle directory, including nested runs. A refresh-local map parses each distinct status.json only once.

Foreground

Stable across updates

Run defaults and per-child model suffixes seed the row immediately; live progress merges preserve metadata instead of dropping it.

Legacy

No invented values

Missing fields remain optional through transport and render as model unknown and reasoning unknown.

Residual risks

  • The suffix parser intentionally recognizes Pi’s current reasoning vocabulary: off, minimal, low, medium, high, xhigh, and max. A future new level would display as unknown until allowlisted.
  • A run whose lifecycle directory cannot be resolved can retry the bounded status RPC on later polls. This preserves eventual discovery but may create small repeated local work.
  • Live end-to-end validation covered representative fixtures rather than every provider and nested workflow combination.

Final recommendation: ship the feature independently of the unrelated dependency-test cleanup.
