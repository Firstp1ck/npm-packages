Design and architecture

The feature specializes only the workflow extension’s existing editor request. It does not change the workflows extension protocol or introduce a code-editor dependency.

Invariant

Structurally read-only

The specialized path contains no textarea or content-editable surface. The generic editor remains unchanged for all other extension requests.

Invariant

Source preserving

Syntax highlighting changes presentation only. Copy and “Back to approval” operate on the original source value.

Invariant

Dependency free

A compact tokenizer highlights comments, strings, numbers, and TypeScript keywords without Monaco, CodeMirror, Prism, or highlight.js.

Independent review finding and resolution

The preliminary Anthropic review found that pressing Enter in the search box with no matches could submit the enclosing method="dialog" form before a response was sent. The finding was accepted after source verification. The handler now prevents the default action for every Enter press before checking match count, and a focused assertion locks in that ordering. Both final reviewers confirmed the blocker was resolved.

Usage, rollout, and residual risks

How it behaves

  1. From workflow launch approval, choose the existing source-preview action.
  2. Search with the source search field; use Enter/Next and Shift+Enter/Previous to move between matching lines.
  3. Use Wrap lines for long commands or prompts and Copy source for an exact copy.
  4. Choose Back to approval to return without changing the script, or Cancel workflow to cancel explicitly.

Residual risks

  • No live-browser/manual viewport run was available; responsive and interaction claims are source- and static-test-backed.
  • Multiline block comments are not colored across physical line boundaries; displayed and returned source remains exact.
  • Search counts matching lines rather than every character occurrence on a line.
  • The shared repository contained unrelated concurrent edits; feature inspection and validation were scoped to the recorded workflow-inspector hunks.

Rollback: remove the specialized branch/helpers, the workflow-script-* CSS block, and focused assertions. The unchanged generic editor remains the protocol-compatible fallback; no migration is required.
