Git directories now open expanded at every depth

When a repository card is opened from a parent workspace such as npm-packages, all directory nodes in the Git Changes and Untracked trees now start expanded. A directory that the user collapses remains collapsed through subsequent in-page rerenders.

Residual risks and usage

Large Git trees

Opening a repository with many nested changed paths can present a taller initial tree. This is intentional; collapse individual branches to retain a compact view during the current page session.

Usage

Open the Git section, then expand the repository card. Changes and Untracked directory branches should already be open. Click a folder summary to collapse or reopen it.

Rollback

Restore const defaultOpen = depth === 0 and the corresponding two test expectations to return to top-level-only expansion.
