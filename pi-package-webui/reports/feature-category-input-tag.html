Architecture and design decisions

Exact contract

Key: feature-category. Values: lightweight-feature, complex-feature, or absent. The browser rejects every other value.

RPC-only producer

The classifier calls ctx.ui.setStatus only when ctx.mode === "rpc", preserving native TUI presentation.

No footer duplication

The dedicated key is consumed before generic statusEntries storage, so the value appears only in the requested composer frame.

Authoritative reconnect

On webui_connected, the active tab's cached category is cleared before retained status replay. Presence and absence both reconcile correctly.
