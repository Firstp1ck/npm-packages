Architecture and lifecycle

Scope precedence

User defaults, then project override

Project identity comes from the active tab’s server-owned canonical cwd. An absent project entry inherits user settings; “Use user defaults” deletes only the active project override.

Responsive editor

Collapsible and container-aware

The editor starts collapsed using native details/summary semantics. Its summary reports dirty and reload state, while a 30rem container query stacks fields based on the side panel’s real width—even when the overall desktop viewport is wide.

Mixed slots

Ordering remains explicit

If one role mixes inherited and explicit slots, guidance retains inherited rows as “use the role/default model” entries. This preserves slot ordinal meaning without creating aliases.

Concurrency

Same-file updates are serialized

A per-settings-file promise queue now closes the in-process lost-update window identified by both reviewers. A focused test holds one updater open and verifies the second cannot enter until the first write completes.

Scope, usage, and residual limits

What changes after save

  • A changed save updates WebUI-owned local settings and displays a reload-required action for the relevant tab.
  • Reloading that tab creates a new session snapshot. Future orchestration is instructed to pass each explicit provider-qualified model and thinking suffix to the original role.
  • Already-running children remain unchanged. Live monitoring continues independently.

Intentional non-goals

  • No changes to installed pi-subagents, its RPC protocol, agent files, or role names.
  • No callable aliases such as reviewer-2, no direct launch button, and no task composer.
  • No fallback-model, tool, skill, prompt, retry-gate, watchdog, or custom-agent configuration.
  • No remote mutation: configuration POSTs remain localhost-only.

Residual risks

Guidance

Prompt adherence is not hard enforcement

Because pi-subagents is unchanged, slots are bounded system guidance. Explicit user instructions and explicit tool-call model fields can override the preset.

Catalog drift

Eight-role compatibility boundary

The role catalog is version-coupled to the installed builtin set. A future role change requires updating the exported catalog and tests.

Browser behavior

No executable DOM harness

Focus restoration and dialog behavior are supported by accessible markup, pure state tests, static contracts, and review, but not a simulated browser test.
