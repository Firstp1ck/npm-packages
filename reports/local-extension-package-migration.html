Source-of-truth architecture

The migration separates package source from machine-local runtime discovery. Pi packages own implementation, documentation, tests, and manifest metadata; the development sync script exposes those resources under the agent directory.

Compatibility finding: directly symlinking the workflow dev extension caused child startup to fail on ../src/errors.ts. The generated wrapper was restored, sync became idempotent again, and the corrected two-reviewer child workflow completed.

Feature routing

@firstpick/pi-extension-feature-system-prompt

Uses the active model in a bounded, tool-free classifier session and injects external feature policy only for classified feature work. Privacy and fallback boundaries are explicit.

Tests: 12/12

Delegation guard

@firstpick/pi-extension-subagent-minimum-fanout

Enforces zero-or-multiple model delegation for direct, task, chain, dynamic, alias, and scheduled subagent requests while preserving management actions.

Tests: 9/9

Recovery

@firstpick/pi-extension-anthropic-auth-recovery

Offers confirmed, authenticated, plan-only compatibility recovery. It keeps prompt files private, forbids automatic apply, and requires explicit secure RPC configuration.

Tests: 8/8

Generalization choices
  • Public READMEs lead with reusable behavior, installation, prerequisites, configuration, security/privacy, limitations, and development checks.
  • Published package files contain no machine-specific absolute paths or private policy bodies.
  • The recovery extension replaced its implicit home-checkout fallback with standard agent paths, explicit environment overrides, and portable ancestor discovery.
  • Conditional and feature policies remain external trusted configuration instead of being embedded in public packages.

Rollout and operator actions

  1. Reload the active Pi process

    /reload

    Future turns then use the package-backed extension sources and restored workflow compatibility wrapper.

  2. Keep publication separate

    The packages are readiness-checked but not published. Use the repository release workflow only under a separate explicit release request.

  3. Untrack two dotfiles links before committing that repository

    git -C ~/.dotfiles rm --cached \
  .pi/agent/extensions/conditional-system-prompts.ts \
  .pi/agent/extensions/feature-system-prompt.ts

    The files remain working-tree symlinks and are covered by .gitignore. This command was intentionally not run because it stages index changes.

Rollback

Remove an affected runtime symlink, restore its previous source from Git or the package source, and reload Pi. Revert migration-owned README/sync/umbrella-patch changes only. No registry rollback is required because nothing was published.
