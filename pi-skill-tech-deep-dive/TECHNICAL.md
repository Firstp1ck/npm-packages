# Technical reference: Tech Deep Dive

Advanced user setup, configuration, compatibility, security, and troubleshooting information.

[Back to the human-friendly README](README.md) · [Contributor and implementation guide](DEVELOPMENT.md)

A Pi skill for tasks involving choosing or evaluating libraries, frameworks, tools, platforms, models, databases, APIs, or architectures for a use case. Produces criteria scoring, ecosystem assessment, and recommendations.

## Install

```bash
pi install npm:@firstpick/pi-skill-tech-deep-dive
```

## Configuration

No required configuration.

## Example view

```text
User: Compare SQLite, Dolt, and PostgreSQL for this offline-first desktop app. Score fit, maturity, maintenance, ecosystem, and migration risk.
Agent: Produces a scored comparison, ecosystem assessment, recommendation, and alternatives.
```
