# Technical reference: Paper Summarizer

Advanced user setup, configuration, compatibility, security, and troubleshooting information.

[Back to the human-friendly README](README.md) · [Contributor and implementation guide](DEVELOPMENT.md)

A Pi skill for academic or technical papers, arXiv/PubMed/IEEE/ACM links, PDFs, methodology review, limitations, practical implications, or extracting findings for engineering decisions.

## Install

```bash
pi install npm:@firstpick/pi-skill-paper-summarizer
```

## Configuration

No required configuration.

## Example view

```text
User: Summarize this paper for an engineering decision. Separate the research question, methods, findings, limitations, and practical implications.
Agent: Produces a structured summary and distinguishes the authors’ evidence from interpretation.
```
